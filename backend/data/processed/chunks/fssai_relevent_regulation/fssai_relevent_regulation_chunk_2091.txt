Sampling Plan.- 
The terms n, c, m and M used in this standard have the following meaning: n = Number of units comprising a sample. c = Maximum allowable number of units having microbiological counts above m for 2- class sampling plan and between m and M for 3- class sampling plan. m = Microbiological limit that separates unsatisfactory from satisfactory in a 2- class sampling plan or acceptable from satisfactory in a 3-class sampling plan. 
M = Microbiological limit that separates unsatisfactory from satisfactory in a 3-class sampling plan. 
 
Interpretation of Results: 
2-Class Sampling Plan (where n,c and m are specified) 
3-Class Sampling Plan (where n,c,m and M are specified) 
1. Satisfactory, if all the values observed are ≤ m 
2. Unsatisfactory, if one or more of the values observed are >m 
1. Satisfactory, if all the values observed are ≤ m 
2. Acceptable, if a maximum of c values are between m and M and the rest of the values are observed as ≤m
